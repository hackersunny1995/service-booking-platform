# Homeprime99 User App

Customer mobile application for Homeprime99 home services booking platform.

## Features

- User authentication (Login/Register)
- Browse service categories  
- View available services
- Search and filter service providers
- Book services with scheduling
- Real-time provider location tracking
- In-app chat with service providers
- Payment processing
- Rate and review services
- Booking history
- Push notifications
- Profile management

## Quick Start

```bash
# Install dependencies
flutter pub get

# Run the app
flutter run
```

## API Configuration

Update backend URL in `lib/config/api_config.dart`

For local development:
- Android Emulator: `http://10.0.2.2:8080/api`
- iOS Simulator: `http://localhost:8080/api`
